# dev-toolbox

> 日常开发脚本与自动化工具集 · Handy scripts & automation for daily development

## 包含 / Includes

| 目录 / Path | 用途 / Purpose |
| --- | --- |
| `scripts/` | 常用运维与调试脚本 / ops & debugging scripts |
| `automation/` | 定时任务与批量处理 / scheduled & batch jobs |

## 约定 / Conventions

- 脚本只依赖标准库，单文件可直接运行 / stdlib only, single-file runnable
- 统一 `--help` 输出 / consistent `--help`
- Shell 脚本遵循 `set -euo pipefail` / strict mode
